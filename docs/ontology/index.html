Description

  • Project ontology for the HistOrniGraph knowledge graph built from the ornithological field diaries of Alfred Laubmann (Bavaria, 1917–1965, 34 volumes). Three grouping classes structure the model: archival units (volume, page, entry, layout region), entry records (what the extraction model reads out of one entry: observations as Darwin Core occurrences, travel events, weather reports) and record details (vocalisations, travel legs); the partonomy between them is explicit (dcterms:isPartOf / hasPart). Taxa, places and persons are shared referents; habitats are NOT a class of this ontology but shared skos:Concepts of lkg:habitatScheme (see the controlled vocabularies), reached from an Observation via dwciri:habitat and mapped to the EUNIS habitat classification (2012) with skos:exactMatch / closeMatch / broadMatch (ontology 0.4.3); places carry owl:sameAs to their GeoNames feature and Wikidata item. The ontology is Darwin-Core-first: wherever a dwc/dwciri, DCTERMS, PROV-O, SKOS, GeoSPARQL or schema.org term exists, the data graph uses that term alone; lkg: terms carry only project-specific meaning (record type, count qualifier, breeding evidence, movement, evidence kind, entry kind, weather, travel, mention roles). Controlled values are SKOS concept schemes in the same namespace; the data graph is validated with SHACL.

  • Project ontology for the HistOrniGraph KG (diary entries, ornithological observations, travel, weather, persons, sources from Alfred Laubmann's field journals). Darwin-Core-first: standard terms are used wherever they exist; lkg: adds only project-specific terms. Grouping classes ArchivalUnit / EntryRecord / RecordDetail plus an explicit dcterms partonomy. Habitats are skos:Concepts in lkg:habitatScheme (dwciri:habitat), each mapped to a EUNIS habitat class (skos:exactMatch / closeMatch / broadMatch); places link to GeoNames and Wikidata (owl:sameAs).

Class Definitions

Archival Unit c

IRI https://w3id.org/laubmann-kg/ontology#ArchivalUnit
Description

A unit of the digitised source: a diary volume, a scanned page, a dated entry or a layout region on a page. Grouping class only (not asserted as rdf:type in the data); the units are connected by dcterms:isPartOf (region → page → volume, entry → page).
Sub Class Of rico:Record
Super Class Of
  • Diary Entry c
  • Diary Page c
  • Diary Volume c
  • Source Region c

Diary Entry c

IRI https://w3id.org/laubmann-kg/ontology#DiaryEntry
Description

The primary semantic unit: a dated, located entry written by the observer — the diarist's day. It is the Darwin Core Event (dwc:eventDate, dwc:verbatimEventDate, dwc:fieldNotes; eventID = entry_uid in the DwC-A) and dcterms:hasPart its observations, travel events and weather reports. dcterms:isPartOf its DiaryPage (or the volume when the page is unknown).
Sub Class Of
  • dwc:Event
  • Archival Unit c
In Domain Of
  • contains observation op
  • contains travel event op
  • date plausible dp
  • entry kind dp
  • entry place op
  • has source region op
  • has weather op
  • mentions person op

Diary Page c

IRI https://w3id.org/laubmann-kg/ontology#DiaryPage
Description

A scanned page of a volume; dcterms:isPartOf links it to its DiaryVolume.
Sub Class Of Archival Unit c

Diary Volume c

IRI https://w3id.org/laubmann-kg/ontology#DiaryVolume
Description

A single bound volume of the field journal (34 volumes, 1917–1965).
Sub Class Of Archival Unit c

Entry Record c

IRI https://w3id.org/laubmann-kg/ontology#EntryRecord
Description

Anything the extraction model reads out of one diary entry: an Observation, a TravelEvent or a WeatherReport. Every entry record is dcterms:isPartOf and prov:wasDerivedFrom exactly one DiaryEntry and prov:wasGeneratedBy the extraction run. Grouping class only (not asserted as rdf:type in the data).
Sub Class Of Entity c
Super Class Of
  • Observation c
  • Travel Event c
  • Weather Report c

Observation c

IRI https://w3id.org/laubmann-kg/ontology#Observation
Description

One taxon record read from a diary entry: a Darwin Core Occurrence (dwc:occurrenceStatus, dwc:individualCount, dwc:sex, dwc:lifeStage, dwc:eventDate, dwciri:recordedBy, dwciri:habitat …) plus the project detail (record type, count qualifier and range, breeding evidence, movement, evidence kinds, vocalisations). An entry with several taxa has several Observations; the DiaryEntry is the event they belong to.
Sub Class Of
  • dwc:Occurrence
  • Entry Record c
In Domain Of
  • breeding evidence dp
  • count qualifier dp
  • evidence kind op
  • flight direction dp
  • has locality op
  • has vocalisation op
  • individual count (maximum) dp
  • individual count (minimum) dp
  • movement kind dp
  • observed at op
  • observed taxon op
  • record type dp
  • verbatim notes dp
In Range Of contains observation op

Person c

IRI https://w3id.org/laubmann-kg/ontology#Person
Description

A person mentioned in the diary (companion, source, collector, cited author) or recorded as observer (dwciri:recordedBy). The role is carried on the mention edge (sub-properties of lkg:mentionsPerson), not on the shared Person node. Name variants merged by entity resolution ("W. Wüst", "Wüst" → "Walter Wüst") are skos:altLabels.
Sub Class Of schema:Person
In Range Of mentions person op

Place c

IRI https://w3id.org/laubmann-kg/ontology#Place
Description

A named location: settlement, locality, region, station, river or route point (dwc:verbatimLocality as written, rdfs:label cleaned, merged spellings as skos:altLabel). Georeferenced places carry geo:lat/geo:long, dwc:decimalLatitude/Longitude and gsp:asWKT. Habitats are NOT places: they are skos:Concepts in lkg:habitatScheme.
Sub Class Of
  • Location c
  • geo1:SpatialThing
In Domain Of place kind dp
In Range Of
  • arrival place op
  • departure place op
  • entry place op
  • has locality op
  • observed at op
  • via place op

Record Detail c

IRI https://w3id.org/laubmann-kg/ontology#RecordDetail
Description

A structured detail of an entry record that cannot be a single literal: a Vocalisation of an Observation, a TravelLeg of a TravelEvent. dcterms:isPartOf its record. Grouping class only (not asserted as rdf:type in the data).
Super Class Of
  • Travel Leg c
  • Vocalisation c

Source Region c

IRI https://w3id.org/laubmann-kg/ontology#SourceRegion
Description

A detected layout region on a scanned page (HistOrniGraph layout stage) whose text became a diary entry; dcterms:isPartOf its DiaryPage. Hook for linking the multimodal (image) corpus.
Sub Class Of Archival Unit c
In Range Of has source region op

Taxon c

IRI https://w3id.org/laubmann-kg/ontology#Taxon
Description

A biological taxon (species, genus, family or informal group) observed or mentioned, keyed by the German vernacular name as the diarist wrote it (dwc:vernacularName; further spellings merged by entity resolution as skos:altLabel). Resolved names carry dwc:scientificName, dwc:taxonRank, the GBIF backbone link (skos:exactMatch / closeMatch / broadMatch, dwc:taxonID) and the GBIF higher classification (dwc:kingdom … dwc:genus).
Sub Class Of dwc:Taxon
In Domain Of
  • GBIF match type dp
  • is bird dp
  • match confidence dp
  • match method dp
In Range Of observed taxon op

Travel Event c

IRI https://w3id.org/laubmann-kg/ontology#TravelEvent

A journey described in a diary entry, made of one or more TravelLegs (train, foot, boat …).

Vocalisation c

IRI https://w3id.org/laubmann-kg/ontology#Vocalisation
Description

A vocalisation noted for an Observation: call type and, when the diarist wrote one, the phonetic transcription. dcterms:isPartOf its Observation, which also carries lkg:evidenceKind lkg:evidence_auditory.
Sub Class Of Record Detail c
In Domain Of
  • call transcription dp
  • call type dp
In Range Of has vocalisation op

Weather Report c

IRI https://w3id.org/laubmann-kg/ontology#WeatherReport
Description

Weather as recorded in the diary entry. The verbatim wording (lkg:weatherVerbatim) is primary; structured values are optional normalisations and never unit-converted (historical entries may use Réaumur). An entry may carry several reports (e.g. morning and evening, distinguished by dwc:eventTime).
Sub Class Of Entry Record c
In Domain Of
  • precipitation dp
  • sky condition dp
  • temperature unit dp
  • temperature value dp
  • weather verbatim dp
  • wind dp
In Range Of has weather op
