Description

  • Project ontology for the HistOrniGraph knowledge graph built from the ornithological field diaries of Alfred Laubmann (Bavaria, 1917–1965, 34 volumes). It models diary entries (the archival record and DwC event), observation events (DwC occurrences: taxon, place, counts, sex, life stage, breeding evidence, movement, evidence, behaviour, habitat, provenance of the record), the diarist's journeys, weather reports, persons and source references. Observations are LLM-extracted from the transcribed diary text; the emitted graph co-emits Darwin Core (dwc/dwciri), PROV-O, DCTERMS, SKOS and schema.org terms next to the project terms, and is validated with SHACL. Controlled values are SKOS concept schemes in the same namespace.

  • Project ontology for the HistOrniGraph KG, modelling diary entries, ornithological observations, travel events, weather, persons and source references from the field journals of Alfred Laubmann. Observations are LLM-extracted from the transcribed diary text; the graph co-emits Darwin Core, PROV-O, DCTERMS and schema.org terms next to the project terms.
